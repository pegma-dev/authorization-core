# @pegma/authorization-contracts

Provider-neutral TypeScript contracts shared by the Authorization Core packages.

```sh
npm install @pegma/authorization-contracts
```

This package defines authorization subjects, policies, identity and entitlement
adapter ports, role-assignment lifecycle types, and signed access-grant
contracts. It contains no provider SDK types and performs no persistence.

See the [Authorization Core documentation](https://github.com/pegma-dev/authorization-core#readme)
for the integration guides and security boundary.
