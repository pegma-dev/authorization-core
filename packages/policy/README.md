# @pegma/authorization-policy

Policy parsing, validation, and diagnostics for Authorization Core.

```sh
npm install @pegma/authorization-policy
```

Policies map application-owned roles and entitlements to explicit permission
strings. Unknown roles and entitlements never grant more than the declared
defaults.

See the [policy reference](https://github.com/pegma-dev/authorization-core/blob/main/docs/POLICY.md).
